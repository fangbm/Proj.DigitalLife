# 私有原始诊断数据

PNG 可能包含通知、状态栏、账号、设备信息；XML 可能包含文本、描述、标识及完整层级。Settings 主界面和普通元数据也不能保证没有私人内容。用户需手动清理通知、关闭敏感弹窗、停留指定主界面。仅批准这些数据的本地兼容性分析，不代表可公开或送给模型。

原件仅保存在独立 owner-only 目录。没有自动上传、模型请求、生活记忆或上下文路径。异常使用固定原因码，不打印 stdout/stderr、serial、完整 fingerprint、授权密文或原始 UI。白名单摘要只含分类、类型、授权/请求/内容哈希、计数、几何、缺失属性、时间及 false 输入标记。

新的合成 PNG/XML 在测试函数内生成，不添加真实完整 XML 到源码 fixture。既有 uptime-api35 三个文件原字节保留，公开例外仍未批准；完整源码 ZIP 因含这些既有夹具标为 LOCAL_PRIVATE_ONLY，不能自动推送。公开摘要不能冒充原始采集记录。

普通 Settings 内容范围无法核实就拒绝。若未来要异常现场，必须另行申请更窄、明确隐私风险的授权；本轮没有异常收集模式。
