## 正常运行路径

`SessionLoop` 启动时读取忽略的 `data/voice.private.json`；只有 `incoming.enabled=true` 才连接本机、带认证的 NapCat SSE 服务。新桥脚本在原 HTTP API 之外配置 `127.0.0.1:31074` 事件端口。当前已登录客户端通过本地管理接口热更新启用了事件服务，没有退出 QQ 或重新扫码。

收到事件后只接受绑定账号、非自身发送者、仍在有效期内的原生 `record` 消息。相同账号/线程/消息 ID 持久去重，自身发出的回复不会再次触发回复。模型无法提供发送目标、任意音源 URL 或修改配置。

处理链为：事件线程 → 当前 QQ 原生消息 → `get_record` WAV → 本地 ASR → 该线程可用文本上下文/关系摘要 → LifeBrain 决定 `send/defer/ignore` → 角色 TTS → 同一 QQ 好友或群的原生语音。可选历史上下文不可用不阻止理解当前真实语音；无法取得音源时明确失败，绝不把通知里的「[语音]」猜成正文。

接收的语音和转写均标记为外部数据，不能改变权限。口头退订在生成回复前生效。沿用当前已有联系人/群范围、关系摘要、发送频率与同一个持久发件箱；实际发送仍核对当前账号和目标路由。群内语音回复发送到原群，不转成给发言人的私信。

本切片针对入站语音选择是否以语音回复，尚未实现所有普通文字社交场景中的文字/语音格式自主选择。微信静默发送和中英混合新音色问题保持未完成。

## 停止、未知发送与缓存

每个语音来源最多一个发送意图；中断或回读不确定保留 `delivery_unknown`，新会话不会自动重放。原生发送计入会话动作预算。取消会关闭事件连接、取消本地转写/合成等待，不留下麦克风或播放器。

本模块复制的原音、规范化音频和转写资产采用短期 TTL。语音处理及会话启动/结束会清理本模块拥有且哈希一致的过期缓存；不删除 QQ 客户端自己的媒体目录。持久收件箱到期清空音源字段。独立 GPT-SoVITS 服务继续遵循 [角色 TTS 生命周期](M6-SILENT-VOICE.md)。

## 使用与验收窗口

正常 `.\start.ps1 -Command Run -Session ...` 会在已启用的当前授权内处理新到的 QQ 语音。只运行桥不会自行开始回复。

专用真人验收入口，在 PowerShell 7、V2 目录运行：

```powershell
.\start.ps1 -Command VoiceListen -Minutes 10 -Session data/sessions/NEW-QQ-VOICE-REPLY
```

它连接真实事件流，只处理窗口内第一条好友语音；调用普通 `SessionLoop.step`，最多回复一条。完成后从 QQ 读回该条原生语音音频，经本地 ASR 与实际生成正文比较。模型可以不回复，不把未发送称为通过。`WINDOW_READY.json` 是就绪状态，`M6_READY.json` 才记录实际闭环结果；无真人语音时窗口到期并停止。

## 2026-10-30 真人语音闭环

实际收到一条约 3 秒的 QQ 好友语音，本地转写后由真实 LifeBrain 生成自然回复，并用小酒狐音色发送一条约 10.46 秒的原生语音。接收方在本聊天中明确试听反馈「清楚，内容正常」。全程只发一条，没有播放扬声器、使用麦克风或重复发送。

平台初次调用约 10 秒后报 SDK 发送确认超时，实际消息约在尝试后 26.3 秒出现在原接收线程。原运行如实保留 `delivery_unknown`；随后通过原线程历史、本人发送者、时间窗内唯一候选和 `get_msg` 原生类型进行只读核对，记为 `sent_observed`，没有重新发消息。

发送现在显式给 NapCat 45 秒确认时间，外层 HTTP 等待 60 秒；仍受会话停止和总时限控制。新增 `VoiceReconcile`，以原发件箱 ID 与实际观察到的消息 ID 核对晚到消息，只能确认观察结果，不能重置意图或重发。候选不唯一、时间/目标/消息不匹配时保留未知状态。

私有证据：`data/m6-a20-live-evidence.json`、`data/sessions/m6-qq-real-voice-reply-20261030-03` 和 `data/sessions/m6-qq-late-record-reconcile-20261030-01`。原先失败状态与后续核对分开保存，不改写旧日志为成功。

精确逐字 ASR 比较未通过：Whisper base 对这段合成音误识别较多，使用 [Systran 官方转换的 Whisper small](https://huggingface.co/Systran/faster-whisper-small) 本地交叉检查后大部分词句正确，仍有少量偏差。模型按固定 revision 下载并验证官方模型文件 SHA-256，只有本地推理，未上传语音；现有 ASR 默认配置未替换。用户试听确认声音清楚、内容正常，因此真实送达与可懂度通过，不能把此结论写成逐字 ASR 完全一致。

核验期间机器内存占用约 98%，曾出现本地 ASR DLL 加载失败；已保留失败记录，并临时暂停本项目自有 TTS 服务完成只读交叉检查。已按原权重与原参数恢复 TTS 服务，并通过正式 `VoiceSynthesize` 再次生成 6.02 秒有效 WAV，未播放、未发送。
