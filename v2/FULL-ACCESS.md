# 完整手机 UI 操作模式

后续版本说明：a4 保留下面的完整 UI 授权，已实测官方 DeepSeek Flash 图片输入并默认开启视觉；a3 当时的文字模式验收记录继续保留，当前行为见 [M3.md](M3.md)。

2026-10-27，用户明确授权“没必要，手机所有权限都可以放开”。版本 `2.0.0a3` 默认启用 `DIGITALLIFE_V2_FULL_ACCESS=true`，沿用 `codex/v2-m2` 分支。该授权覆盖原设计的只读业务边界；不导入 V1 数据的要求继续有效。`M2-DELIVERY.md` 保留 a2 当时的事实，本文件说明当前后续修改。

## 当前行为

- 不再按按钮名拒绝付款、发送、删除、确认、安装、权限、账号或设置等操作；未知名称的可点击按钮也能成为模型候选。
- 密码、验证码、一般编辑器、权限对话框与多任务内容按真实页面保留，不因这些语义整屏遮蔽。
- 多任务 PNG 不再单独屏蔽。`VISION=true` 时按普通页面附图；默认 `VISION=false` 仍使用 XML/文本，未更换模型或假定现有端点支持图片。
- `type_text(control_id,text)` 为聚焦通用编辑框提供选中替换，不自动提交。先 tap 聚焦，再 type_text；提交、发送或保存由模型另选当前按钮。搜索仍使用专门的核对后回车流程。
- 通用文本支持 1–160 个可打印 ASCII 字符，含邮件地址和标点。中文、换行、字面量 `%s` 尚不受现有 ADB 输入传输支持。文本以单个正确引用的 shell 参数传输，单引号、分号、反引号和 `$()` 不会成为命令。

这是 V2 的 UI 操作与观察策略。不会在开发时批量修改设备上所有应用的 Android 权限；模型可以在真实出现的权限弹窗或设置页中操作。

设备绑定、OS 独占锁、STOP/紧急停止、预算与时限、当前控件及焦点复核、分发前日志、独立后观察、未知结果屏障保持有效。失效控件、明确被遮挡的目标和缺失 XML 仍不会误当成可用输入；它们属于执行正确性检查。没有自动重播或自动续跑。需要原限制模式时显式设置 `DIGITALLIFE_V2_FULL_ACCESS=false`。
