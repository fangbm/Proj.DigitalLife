# M5 本机功能验收与 a14 修复

后续 a15 已按用户要求取消正常路径的重复资料、成员及头像核对，见 [流程简化](SIMPLIFIED-FLOWS.md)。以下保留 a14 实机测试时的实际行为和证据。

2026-10-29，`2.0.0a14`，分支 `codex/v2-m5`。**本机 B站、QQ 和主微信范围的 M5 功能验收完成**：已有实际评论/原线程回复和正确群中的官方卡片发送、发后观察证据；本轮主微信完整自动链路也已通过。以下结果以真实手机 UI、原生身份与发件箱证据为准，未把离线测试算作真实发送。

## 完成标准的更正

用户提供的 v2.4 文档第 13.4、14 节要求：授权账号实际评论/回复，以及公开视频链接或正常平台卡片在正确授权群中发送并经观察核对；第 7 节明确允许视频平台互动通知与可访问评论 UI 作为事件来源。此前 a13 把“Android 系统推送必须到达”和“一轮不经独立复核直接成功”同时视为 M5 硬门槛，判断过严。a12 的实际评论、原线程回复、QQ 官方卡片与主微信官方卡片证据已满足上述最低功能证据；a13 的历史失败记录原样保留。

本轮额外验证从桌面进入应用内评论、原线程核对、模型单次回复，以及微信修复后的完整自动核验。系统推送是否实际到达仍独立报告，不将应用内读取宣称为系统通知触发，也不将功能验收等同于长期无人值守可靠性。

这次新卡片来自关注列表中实际读取、采样并绑定编号的《音理陪你读论文｜Attention Is All You Need》。175 为零发送的视频来源准备，200.8 秒、15 次 UI 输入、1 次模型请求；没有宣称看完全片。此前来源准备 170–174 的失败均为零发送，记录保留，最终使用 175 的实际新来源，没有重复旧卡片或改发裸链接。

169 是**脚本选择语义测试步骤、生产代码执行、真实模型决定草稿与发送、事后证据复核**，不是自由自主规划测试，也不是系统通知触发。线程 ID 来自本轮真实 UI 检查结果，没有由操作者预填或伪造通知。初次测试配方 166–168 均在外发前停止：前两次为测试范围筛选未接受规划动作，168 暴露桌面进入适配问题；这些失败不隐藏或改写为成功。

## 修复

从桌面执行 `inspect_video_replies` 时，旧 `BilibiliUI.home_page()` 直接报 `BILI_APP_FOREGROUND_CHANGED`。a14 在其他应用或桌面前台时通过实时清单中的正常 Launcher 启动 B站，然后重新核对实际前台包，再继续账号、原视频和线程身份检查。启动返回其他包或出现未知分发时停止，不自动重放或在其他应用里盲目返回。

回复发后核验现在支持“父评论滚出屏幕、上方只露出旧的本人回复”的真实情况：必须有哈希未变的原线程/发送者证据，发前发后均出现同一真实来信，且上方每段旧回复都精确对应这个原始父评论下已观察成功的本人发件箱记录。未知上文、错误父评论、篡改证据仍不确认；不靠昵称或相似正文猜测线程。

完整操作模式下，滚动手势的最小可见高度现在同时参考实际原生容器高度，支持位于屏幕下部的嵌套视频列表。顶部/底部保留区、原生可滚动角色、当前场景与窗口遮挡检查保持；限制模式的原有最小范围不变，极小或不可滚动区域仍拒绝。发前校验和固定手势生成使用同一范围计算。

按用户本轮要求，**评论来信的发送者 UID 改为可选信息**：默认流程留在原评论详情，读取并重新核对具体来信，不再为回复跳到对方主页。没有对方 UID 不会阻断回复；原视频、原始本人评论、对应详情入口、完整正文与原生回复按钮仍绑定到具体目标。新记录保留四组实际线程截图/XML，不声称读取了没有取得的对方 UID。

当前登录账号和视频来源仍按实际资料字段核对；需要读取 UID 的地方只接受原生 `bottom_tags_layout` 专用标签容器中的可点击数字字段，不接受装饰编号。历史带 UID 的线程记录若继续使用，也必须通过同一原生来源检查。为避免解析修复或改成可选字段后重复回复，历史记录仍参与去重；无效的旧字段只可保守地用于阻止重发，不能作为发送授权。独立纠正证据关联旧记录，原始字段不覆盖。

用户明确要求的单张官方卡片验收使用原有十分钟、单一来源、单一群的一次额外测试范围，并与普通自主联系冷却区分。176 在发送前因历史时间晚于当前电脑时间而触发冷却，未生成发件箱或发送；修复后仅在该有限验收范围内不使用自主联系冷却。普通运行的冷却、全局频率、权限、退订和未知发送屏障不变，已有意图仍禁止重发；旧时间戳不改写。

## 范围与清理

本轮 B站只发布一条新回复，主微信只发送一张新卡片，QQ 不重发。结束时手机回到桌面，通知采集关闭、音频投射释放；无待核对输入屏障、IME 恢复文件或本轮存活测试进程，自主生活记忆仍为 18 条。

M5 完成范围是上述当前本机 App 路径。B站 Android 系统推送到自动回复的链路仍未取得实机成功证据，不把应用内读取冒充推送触发；抖音、长期无人值守可靠性和 M6–M8 不包含在本轮验收。群卡片出现在本机 UI 不等于对方已读或服务器送达。
