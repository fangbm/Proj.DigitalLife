# a15 会话流程简化

2026-10-29，`2.0.0a15`，分支 `codex/v2-m5`。按用户“全部去掉”的要求，取消此前审查列出的重复身份核对。默认动作改为复用配置账号和已有会话，读取当前目标与正文，执行后读取结果。

| 路径 | 已取消的操作 | 当前行为 |
| --- | --- | --- |
| QQ / 微信私信 | 逐次打开本人资料、联系人资料、好友管理页，寻找删除好友入口 | 复用配置账号和已存会话；已在目标聊天页时直接使用 |
| QQ / 微信群聊 | 逐次打开群设置、查群号、比对成员和人数 | 复用会话绑定与当前群标题；人数变化不重建绑定；群 @ 使用当前消息和 App 的 @我 提示 |
| 官方视频分享 | 分享前后重复查本人、群资料和成员，提取并比对本人头像、群头像 | 选择官方选择器内的实际群名行，发送前读取官方预览的目标和视频；发送后读取原会话新增卡片 |
| B站观看 | 打开 UP 主资料再查 UID 和关注关系 | 使用当前视频的编号、标题、作者名及关注按钮；没有 UID 时保留为空 |
| B站评论与回复 | 逐次打开本人主页；刚检查完原线程又退出并重走历史记录 | 使用配置账号；同一视频直接使用，刚检查的线程在操作上下文未改变时直接接续 |

B站对方 UID 在 a14 已从默认回复路径移除；a15 同时去掉本人和 UP 主资料页跳转。历史证据解析工具保留兼容性，不会在正常发送路径自动调用。

当前目标、输入正文和发送结果仍从实际页面读取。官方卡片保持 App 官方分享，不自动改发裸链接。防重复发送、发送结果未知时停止、紧急停止和会话预算保留；未知发送不会因本次简化获得重发许可。新增卡片结果使用本次客户端发送完成及前后卡片变化，不再宣称通过本人头像确认，也不宣称服务端送达或已读。

账号使用操作者配置，不再每轮自动发现手机手动切换的登录账号。首次会话使用 `ui-chat:` 本地引用，后续优先复用已有平台绑定；不把标题派生引用称为 QQ 号、微信号或平台内部群 ID。相同显示名的不同会话不再通过资料页消歧。上述行为是取消这些核对后的直接结果。

本轮验证仅使用离线测试与独立安装包，没有再向联系人、群或公开视频发送测试消息。M5 原有本机实测结果继续见 [a14 验收记录](M5-FINAL-ACCEPTANCE.md)，不将其改写为 a15 的新实机测试。

验证结果：源码与独立安装的 wheel 各 292 项测试通过，包含 14 项新增测试；29 个运行模块与源码逐字节一致。新增回归覆盖当前会话原地刷新、私信草稿读取、账号配置复用、群人数变化、官方选择器实际目标行、无头像的卡片结果读取、无 UP 主 UID 的来源绑定，以及跨决策轮继续原回复线程。V1 README 历史区逐字节保持。
